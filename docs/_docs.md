# Nova documentation index

Supporting documentation for Nova. Start with the [main README](../README.md) for the overview and quick start.

The documentation is split across two folders:

- **`docs/`** (this folder) — the architecture overview, platform notes, README translations and the image inventory.
- **`help/`** — the step-by-step guides: what Nova is, how to install and use it, how the JSON brain works and how to write skills.
